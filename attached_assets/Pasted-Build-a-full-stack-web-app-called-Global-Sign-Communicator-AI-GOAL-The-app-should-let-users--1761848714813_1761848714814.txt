Build a full-stack web app called "Global Sign Communicator AI".

🎯 GOAL:
The app should let users speak or type text, then:

Convert that text into ASL (American Sign Language) signs using a 3D avatar.
After showing ASL, allow the user to select a target language (like Hindi, Spanish, German, Japanese, Korean, Chinese, French, Arabic, Italian, etc.).
Translate the original text into that selected language.
Use Text-to-Speech (TTS) to pronounce the translated text in that language.
Display sign language of the translated text using the avatar (for example, KSL for Korean).
Final result = Text/Speech → ASL → Translation → Target Text + Speech + Target Sign.

Frontend: HTML, CSS, JavaScript (use Three.js or Ready Player Me avatar for 3D animation)
Backend: Python Flask
Use gTTS for speech synthesis
Use Google Translate API or “translate” Python library for multilingual translation
Avatar signs can be represented by short animations or hand gesture GIFs (mock if real API unavailable)

### Troubleshooting Steps:
Confirm the Flask backend server is running:
Run in terminal


python3 backend/app.py
and ensure no errors on startup.

Verify the backend is listening on port 5000 (default Flask port).

Check the frontend API call URLs point to http://localhost:5000/api/translate (or correct backend address).

Make sure CORS is enabled on the backend to allow requests from your frontend origin.

Open browser DevTools (F12) Network tab and check if the /api/translate request is sent and what response or error it shows.

Review backend logs for incoming requests or errors.

Confirm frontend and backend are running on the same machine or accessible over network.

Following these steps will help you identify why the translation backend is not reachable or responding, then fix it accordingly.
